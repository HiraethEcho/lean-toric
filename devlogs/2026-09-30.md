## 网络问题（重要）

`elan` 下载 toolchain 只有 ~25 KB/s，8 分钟才 16 MB，而包有 **553 MB**。
实测：

| 线路 | 速度 |
|---|---|
| 单连接 → github releases | ~25–65 KB/s |
| 4 连接并起来 → github releases | ~330 KB/s（**被 per-connection 限速**） |
| TUNA / USTC / NJU | **没有 lean 镜像**（404） |

所以 elan 原生下载要 2 小时以上。已经写了 `scripts/fetch.sh` 解决：

- 按字节区间切片，N 个连接并发拉，每片单独落盘
- 中断后重跑同一条命令即可续传（完整的片跳过，短的/坏的片重下）
- 拼接后校验总长 + sha256
- 实测：8 连接跑 2MB 与串行下载**逐字节一致**；`scripts/test_fetch.sh`
  15 条断言全过（含断点续传、已完成跳过、sha 不匹配报错、`--conns 1`）

`scripts/install_toolchain.sh` 把 fetch + 解包 + `elan toolchain link` 串起来，
替掉 `elan toolchain install`。`DRYRUN=1` 可预览 URL 和 sha256。

toolchain 校验值（从 GitHub API 自动取，已确认）：

```
lean-4.34.1-linux.tar.zst   580432872 bytes
sha256 47bf4bbd78f70c2e9670598ab7124d92b6efb7330ff33e5fbb4030f6fd72e4e4
```

下载路径：`downloads/lean-4.34.1-linux.tar.zst` → 解包 `versions/v4.34.1/`
→ elan 里是软链 `leanprover--lean4---v4.34.1`。各层目录名都带版本号。

**另一个坑**：`lake exe cache get` 从 `mathlib4.blob.core.windows.net` 拿
mathlib 的 `.olean`，这个域名在当前 DNS（192.168.1.1）**解析失败**。
没有 cache 就得从源码编译 mathlib —— 本机 20 核，大概 3–5 小时。
网络好了先测这个域名通不通；不通的话要么换个 DNS，要么改用别的 cache 源。
