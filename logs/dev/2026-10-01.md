## 下载：之前 25 KB/s 的判断作废

网络一恢复就是 **7.8 MB/s** 聚合（16 连接）。553 MB 的 toolchain 用了
约 70 秒下载 + 2 分钟解包。`fetch.sh` 16 片**一次全过**，sha256 校验通过。

结论：`fetch.sh` 的价值不是"今天快 300 倍"，而是**网络差的时候不废**。

## 更正：mathlib cache 的 DNS 是我判断错了

之前记录「`mathlib4.blob.core.windows.net` 解析失败」——**这个域名在
mathlib v4.34.1 里根本不存在**。源码里真正的 cache 主机是：

```
Cache/  →  lakecache.blob.core.windows.net
```

用 DNSPod 和 114DNS 查过，`mathlib4.blob.core.windows.net` 是 NXDOMAIN
（Status 3，还带 Azure 自己的 SOA）—— 因为它就不该存在。真实的
`lakecache` 一切正常，`lake exe cache get` 拿到 8908 个文件。

教训：先读源码里的常量，再怀疑网络。

## 我自己犯的两个错

1. **lakefile 的 globs 写错**。`globs = ["Repro", "Toric"]` 会让 lake 去找
   `src/Toric.lean`，但那个文件不存在（只有空目录）→ `lake build` 报
   `no such file or directory`。补了 `src/Toric.lean` 根模块就好了。
2. **Smoke 测试自己写错两处 Lean 语法**：
   - `Point (x := 1, y := 2)` —— 逗号非法
   - `Point (x := 1) (y := 2)` —— 具名实参对结构体不合法
   - 正确写法是结构体实例语法：`({ x := 1, y := 2 } : Point)`
   - 这正是 `WallData` 那类 record 会用到的写法，记下来。

## 第一份练习的分寸

`01Rewriting.lean` 共 6 道题。我的处理：

| 题 | 给了什么 | 为什么 |
|---|---|---|
| 1 `(a+b)² = ...` | **什么都没给** | 答案就是 `ring`，而上一段例子里已经写着。敲一遍比看我敲有用 |
| 2 `a + b = c + 4*d` | `rw [h]` + 写清新目标 | 给出"重写后目标会变"的模式 |
| 3 `exp (a+b-c)` | `rw [exp_sub]` + 新目标 | 剩下的是找 `exp_add` / `exp_zero` |
| 4 `b + c = d` | `rw [← h'']` + 新目标 | 这题考方向，`←` 是关键起手式，必须给 |
| 5 `calc` 五行 | 第一行 `rw [h]` | 教 `calc` 形状；后四行自己接 |
| 6 `calc` 三行 | 架子 + 第一行 | 顺便教"先写 `:= ?_` 再填"的工作流 |

一个判断供你确认：**一 tactic 的题我选择不给答案**。规则写的是"可以给前 1–2 个"，
不是"必须给"。给了就没有"我证出来了"的反馈。你觉得该给就说一声。
